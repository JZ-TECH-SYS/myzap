# 🤝 Contribuindo

Obrigado por considerar contribuir com o **MyZAP**! 

## Como Contribuir

### 1. Reportar Bugs

Encontrou um bug? Por favor, abra uma [issue](https://github.com/JZ-TECH-SYS/myzap/issues) incluindo:

- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs atual
- Versão do Node.js e sistema operacional
- Logs relevantes

### 2. Sugerir Melhorias

Tem uma ideia? Abra uma [issue](https://github.com/JZ-TECH-SYS/myzap/issues) com:

- Descrição detalhada da funcionalidade
- Justificativa (por que seria útil)
- Exemplos de uso

### 3. Pull Requests

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas mudanças (`git commit -m 'Adiciona MinhaFeature'`)
4. Push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um Pull Request

#### Boas Práticas

- ✅ Siga o estilo de código existente
- ✅ Adicione comentários quando necessário
- ✅ Teste suas mudanças localmente
- ✅ Atualize a documentação se necessário
- ✅ Seja claro e descritivo nos commits

## Código de Conduta

Este projeto segue um código de conduta básico:

- 🤝 Seja respeitoso com outros colaboradores
- 💬 Mantenha discussões construtivas
- 🚫 Não toleramos assédio ou comportamento ofensivo
- ✨ Celebre contribuições de todos os níveis

## Dúvidas?

Entre em contato através das [issues](https://github.com/JZ-TECH-SYS/myzap/issues) ou grupos de suporte.
